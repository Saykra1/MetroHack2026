# Hackathon workspace

| Path | Purpose |
|---|---|
| `LOG.md` | Chronological log: what was done, result, conclusion |
| `TASK.md` | Task statement, metric, constraints, organizer chat Q&A |
| `INSIGHTS.md` | Data / domain insights, leaks, non-obvious angles |
| `DECISIONS.md` | Decisions made, alternatives rejected, why (ADR-lite) |
| `AGENTS.md` | Agent roles and protocol |
| `LEADERBOARD.md` | Every experiment: id, idea, local CV, public score |
| `task/` | Raw task files, organizer chat |
| `data/` | Raw + processed data (never edit raw) |
| `research/` | Prior-art reports (similar competitions, SOTA, papers) |
| `src/` | Solution code |
| `experiments/` | One folder per experiment |
| `submissions/` | Submission files, named `<date>_<exp-id>_<score>` |
| `pitch/` | Demo, slides, speech |
